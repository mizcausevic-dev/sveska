A studio-grade, local-first notepad. The system extracts every value directly from tokens.css and BRAND.md — no inventions, no rainbow. One sharp accent (amber), one signal color (cyan, AI / live state), and a paper-on-ink hierarchy.

Toggles the page chrome only. Components below show both at once.

01 — Easings

Four curves, four jobs.

Use the smallest set possible. Sveska is restrained. Linear is never used for spatial motion. Back is reserved for the keyboard chord and the empty-state glyph entrance — overshoot signals intent.

03 — Accessibility

Reduced-motion behaviour.

Sveska respects prefers-reduced-motion: reduce and a manual override in /settings/appearance. Every motion atom must have a defined non-motion form — never just disable, always replace.

Atom prefers-reduced-motion: reduce Sveska override Replacement
Snapshot pulse honored auto · off · on Ring becomes static; dot keeps halo
Save flash honored auto Press color only · no halo, no Y shift
Modal in / out honored auto Fade only · no scale, no Y translate
Command palette honored auto Fade · backdrop instant · no scale
App shell mount honored auto Opacity 0 → 1 · positions instant
Focus mode honored auto Cut · no slide-out chrome
Keycap chord (onboarding) replaced auto Static "⌘N" keycap · 1.4 s hold
Caret blink honored auto Solid amber bar · no blink
04 — Implementation

Drop-in snippets.

The atoms are pure CSS where possible. The motion-piece (M0 onboarding) uses the timeline engine in animations.jsx. Everything else can live in system.css.

SNAPSHOT PULSE · CSS
/* Honor reduced motion at the source */
.snap-dot {
  width: 8px; height: 8px;
  border-radius: 999px;
  background: var(--signal-400);
  box-shadow: 0 0 0 3px
    color-mix(in oklab, var(--signal-400) 22%, transparent);
}
.snap-dot::after {
  content: "";
  position: absolute; inset: 0;
  border-radius: 999px;
  border: 1.5px solid var(--signal-400);
  animation: snap-pulse 2.4s ease-out infinite;
}
@keyframes snap-pulse {
  0%   { transform: scale(1);   opacity: .45; }
  100% { transform: scale(2.8); opacity: 0;   }
}
@media (prefers-reduced-motion: reduce) {
  .snap-dot::after { animation: none; }
}
MODAL ENTER · CSS
.modal {
  animation: modal-in 180ms
    cubic-bezier(0.33, 1, 0.68, 1) backwards;
}
.modal[data-leaving] {
  animation: modal-out 140ms
    cubic-bezier(0.65, 0, 0.35, 1) forwards;
}
@keyframes modal-in {
  from {
    opacity: 0;
    transform: translateY(8px) scale(.96);
  }
}
@keyframes modal-out {
  to {
    opacity: 0;
    transform: translateY(8px) scale(.96);
  }
}
@media (prefers-reduced-motion: reduce) {
  .modal, .modal[data-leaving] {
    animation: none;
    opacity: 1;
  }
}
SAVE FLASH · JS-DRIVEN ONE-SHOT
// Triggered on every successful snapshot save.
function flashSaveButton(el) {
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    el.style.background = 'var(--amber-700)';
    setTimeout(() => el.style.background = '', 120);
    return;
  }
  el.classList.add('flashing');
  el.addEventListener('animationend', () =>
    el.classList.remove('flashing'), { once: true });
}

/* .flashing → 600ms keyframe: amber-500 → -700 → -500
   + box-shadow halo (35% amber, 4px) + translateY(0 → 1 → 0) */

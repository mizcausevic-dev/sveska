Parking lot · open decisions.

Things we have decided not to decide yet. Each one has a clear trigger — the conditions under which it gets revisited. None of these is rejected; none of them is committed.

P1 · CANVAS LICENSE

tldraw vs Excalidraw, in production.

tldraw 4.x is dev-only free; production needs a license (~$6k/yr) or hobby with forced watermark. Excalidraw (MIT) ships in M5. We will revisit only when revenue justifies the license.

trigger · MRR ≥ $15k/mo for 3 consecutive months
P2 · EDGE HOST

Cloudflare Workers vs Vercel Edge.

Both connectors are viable. Workers is cheaper and has a longer free tier; Vercel has tighter local-dev. Decision is reversible; the proxy contract is portable.

trigger · M4 kickoff · whoever is on call that week chooses
P3 · SYNC

Cross-device, multi-user.

We will ship sync only if it is end-to-end encrypted with client-held keys. Otherwise it is not shipped. This is a non-negotiable from CLAUDE.md §5.

trigger · post-M6 · and only after a working E2E prototype
P4 · ANALYTICS

Cookieless, self-hosted, consent-gated.

We need some signal for the funnel work in M6. We will never use a tracker that fingerprints users or hits a third-party domain. Plausible self-hosted is the leading candidate.

trigger · M6.3 kickoff · separate review board
